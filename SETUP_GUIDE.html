Watermelon Calendar Widget

Windows 11 setup guide · Google Calendar + Outlook.com + Private ICS · read-only

What you are installing

The widget opens above other windows in the top-right corner, can be moved or resized, and hides to the Windows notification area when minimized. The pin button lets other windows cover it when desired. It displays one day or three days at a time and refreshes selected calendars every 10 minutes.

Privacy: passwords are entered only on Google or Microsoft sign-in pages. The widget requests read-only calendar access. Sign-in tokens, the Google client secret, private ICS addresses, and the local event cache are encrypted for your Windows account using Windows Data Protection.

Version 1.3 additions and corrections

  • The main widget now uses Windows 11's native minimize, maximize, and close buttons.
  • The previous and next date buttons now use proper vector chevrons instead of text characters.
  • Every Google sign-in attempt uses a fresh secure callback port, so a failed approval screen cannot block the next attempt.
  • You can cancel an in-progress browser sign-in and retry immediately.
  • You can add a secret, read-only ICS feed without Google browser approval.
  • A vector pin button beside Refresh switches between always-on-top and normal window stacking.
  • Displayed calendar names are converted to plain standard characters, removing accents, emoji, and malformed symbols.

1Install the widget

  1. Extract the downloaded ZIP file.
  2. Double-click Install.cmd. Windows may ask whether you want to run it because this personal app is not code-signed. Choose Run anyway only if you downloaded the ZIP from the official project repository and trust its contents.
  3. The installer creates watermelon shortcuts on the desktop and Start menu, adds the widget to Windows startup, opens this guide, and launches the widget without a PowerShell or Windows Terminal window.
  4. To keep it on your taskbar, right-click the desktop shortcut and choose Show more options → Pin to taskbar. Selecting that watermelon icon later will open or restore the existing widget.

2Add a private ICS calendar (easiest Google option)

This avoids OAuth and Google app approval. It remains read-only and refreshes from the original calendar every 10 minutes.

  1. On a computer, open Google Calendar, then choose Settings.
  2. Under Settings for my calendars, select the calendar you own.
  3. Open Integrate calendar and copy Secret address in iCal format. Do not use the ordinary public address.
  4. In Watermelon Calendar, open Settings and select + Private ICS.
  5. Enter a display name, paste the secret address, choose a color, and select Add calendar.
  6. Leave it checked and select Save and refresh.

Keep this address secret. Anyone who has it may be able to read that calendar. If it is exposed, return to Google Calendar's Integrate calendar page and select Reset, then remove and re-add the feed in the widget. Google may hide the secret address when you do not own the calendar or your sharing permissions are insufficient.

3Create Google browser sign-in credentials (optional)

Do this once for your Google calendars. A Google Cloud project and the Calendar API are free for this personal-use volume.

  1. Open the Google Cloud Console. Create a project named Watermelon Calendar Widget.
  2. Open APIs & Services → Library. Search for Google Calendar API and enable it.
  3. Open Google Auth Platform. Configure Branding with your email and the app name. Choose an External audience if asked.
  4. Under Data Access, add https://www.googleapis.com/auth/calendar.readonly, plus openid and email identity access if the console asks you to declare scopes.
  5. Add the exact Google address you will use with the widget as a test user. This is required while the publishing status is Testing. Save the Audience page before attempting sign-in.
  6. Under Clients, create an OAuth client. Choose Desktop app. Copy both the Client ID and Client secret immediately. Google may show the secret only once.
  7. For uninterrupted syncing beyond seven days, change the app publishing status from Testing to In production. A personal, unverified app may show an extra warning during sign-in. Confirm that this is your own project and continue. Leaving it in Testing normally makes the Calendar refresh token expire after seven days.

Google changes console labels occasionally. Its official desktop OAuth instructions are here.

4Create Outlook.com browser sign-in credentials

  1. Open the Microsoft Entra admin center using your personal Microsoft account.
  2. Choose Identity → Applications → App registrations → New registration.
  3. Name it Watermelon Calendar Widget. Choose the account type that includes personal Microsoft accounts. If available, choose Personal Microsoft accounts only.
  4. Open Authentication → Add a platform → Mobile and desktop applications. Add this exact custom redirect URI: http://localhost:53682/.
  5. Open API permissions → Add a permission → Microsoft Graph → Delegated permissions. Add Calendars.Read and User.Read.
  6. Return to Overview and copy the Application (client) ID. No Microsoft client secret is needed.

Microsoft's official desktop app registration guidance is here.

5Connect accounts and choose calendars

  1. In the widget, select the Settings icon, then + Google, + Outlook, or + Private ICS.
  2. Paste the requested Client ID. Google also asks for the Client secret. Select Open secure sign-in.
  3. Complete sign-in in your browser and approve read-only calendar access.
  4. Repeat for any additional personal Google or Microsoft accounts.
  5. Select up to 20 calendars, then choose Save and refresh.

Troubleshooting

  • Google displays a hard “Access blocked” or “not approved” error: open Google Auth Platform → Audience and confirm that the exact account you selected in the browser is listed under Test users. Also confirm that the OAuth client type is Desktop app and that Calendar read-only access is declared under Data Access.
  • Google displays a warning that the app is unverified: confirm that the project name and developer email are yours, choose Advanced, and continue to your personal app. A warning screen is different from a hard Access blocked error.
  • Google stops syncing after seven days: the OAuth app is probably still in Testing. Publish it to production or reconnect weekly.
  • Microsoft reports a redirect mismatch: verify that http://localhost:53682/ is registered exactly, including the trailing slash.
  • A calendar shows a sync issue: open Settings, remove the affected account, and connect it again.
  • A private ICS calendar stops syncing: its secret address may have been reset. Remove that Private ICS source and add the current secret address again.
  • The widget disappeared: check the notification-area overflow menu near the Windows clock and double-click the widget icon. You can also launch it from the watermelon desktop or taskbar shortcut.
  • Installation does not finish: extract the entire ZIP before running Install.cmd. Version 1.4.4 verifies the PowerShell program, stops and replaces any earlier launcher, creates a Windows PowerShell 5.1-compatible console-free launcher, and reports errors instead of silently continuing. If it still fails, open %TEMP%\WatermelonCalendarWidget-Install.log.
  • Want to uninstall: run Uninstall.cmd from %LOCALAPPDATA%\WatermelonCalendarWidget. It removes the widget, encrypted tokens, and locally cached event details.
